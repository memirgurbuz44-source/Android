# İlk Uygulamam — Emir Gürbüz

Bu, Android için hazırlanmış küçük bir Kotlin uygulamasıdır.

- Ekranda **Bana Tıkla** düğmesi bulunur.
- Düğmeye basıldığında **Emir Gürbüz** yazısı görünür.
- Uygulama internet izni istemez ve çevrimdışı çalışır.

## APK oluşturma

1. Android Studio'yu aç.
2. **Open** seçeneğiyle bu depoyu bilgisayarına indirip aç.
3. Gradle eşitlemesinin tamamlanmasını bekle.
4. **Build → Build Bundle(s) / APK(s) → Build APK(s)** yolunu izle.
5. APK şu konumda oluşur: `app/build/outputs/apk/debug/app-debug.apk`

## Teknik bilgiler

- Kotlin
- Android Gradle Plugin 8.7.3
- Minimum Android sürümü: Android 6.0 (API 23)
- Sunucu veya internet bağlantısı gerekmez.
